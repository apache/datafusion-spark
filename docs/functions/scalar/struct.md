# Struct Functions (scalar functions)

Part of the [datafusion-spark function reference](../README.md).

- [struct](#struct)

## `struct`

Returns a struct with the given expressions as its fields. Unlike DataFusion's `struct`, the fields are named `col1`, `col2`, ... as in Spark, rather than `c0`, `c1`, ...

```sql
struct(expr, ...)
```

### Arguments

- **expr**: One or more expressions of any type, each becoming a field of the struct.

### Example

```sql
> SELECT struct(1, 2, 3);
{col1: 1, col2: 2, col3: 3}
> SELECT struct(1, 'a', NULL);
{col1: 1, col2: a, col3: NULL}
```
