# JSON Functions (scalar functions)

## `json_array_length`

Returns the number of elements in the outermost JSON array. Returns NULL for a NULL input, an empty or blank string, invalid or truncated JSON, and any valid JSON value that is not an array. Like Spark, the array is read up to its closing bracket and anything after it is ignored. Known differences from Spark, which parses with Jackson configured to accept single-quoted strings and unescaped control characters (Hive compatibility): those inputs return NULL here. Jackson also limits nesting to 1000 levels and number literals to 1000 digits, and Spark returns NULL beyond those limits, while such arrays are still counted here.

```sql
json_array_length(json_array)
```

### Arguments

- **json_array**: String expression containing a JSON array. Other types are rejected at planning time. NULL returns NULL.

### Example

```sql
> SELECT json_array_length('[1,2,3,[33,44],{"key":[2,3,4]}]');
5
> SELECT json_array_length('[1,2] trailing');
2
> SELECT json_array_length('{"key":"not a json array"}');
NULL
> SELECT json_array_length('[1,2');
NULL
```

## `json_tuple`

Returns the values of the given top-level fields of a JSON object, as a struct with one string field per key, named `c0`, `c1`, ... DataFusion has no built-in `json_tuple`. In Spark, `json_tuple` is a generator that returns one column per key. A scalar function returns one value per row, so here the columns are wrapped in a struct, which the caller (e.g. Comet) is expected to unpack. Keys are case-sensitive. A missing field, a JSON `null` value or a NULL key gives a NULL field, and non-string values such as numbers are returned as their JSON text. Returns NULL if the input is NULL, is not valid JSON, or is not a JSON object.

```sql
json_tuple(json_str, key1[, key2, ...])
```

### Arguments

- **json_str**: String containing a JSON object. NULL, invalid JSON or JSON that is not an object returns NULL.
- **key**: One or more string keys of top-level fields to return. A NULL key gives a NULL field.

### Example

```sql
> SELECT json_tuple('{"a":1, "b":"x"}', 'a', 'b', 'c');
{c0: 1, c1: x, c2: NULL}
> SELECT json_tuple('[1, 2]', 'a');
NULL
```
