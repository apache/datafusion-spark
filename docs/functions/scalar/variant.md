# Variant Functions (scalar functions)

Part of the [datafusion-spark function reference](../README.md).

- [is_variant_null](#is_variant_null)

## `is_variant_null`

Returns true only if the VARIANT value is a variant null, which is a JSON `null` stored in a VARIANT, and false otherwise. A SQL NULL returns false, so the result is never NULL. A VARIANT is the struct of the Arrow `arrow.parquet.variant` extension type, with a binary `metadata` field and a binary `value` field, and the function reads the first byte of `value`. An empty `value` raises `[MALFORMED_VARIANT]`. Any other argument type is rejected at planning time, with no implicit casts, as in Spark. Spark has had `is_variant_null` since 4.0.0 and has no VARIANT type before that.

```sql
is_variant_null(variant)
```

### Arguments

- **variant**: VARIANT expression: a struct with a binary `metadata` field and a binary `value` field. A NULL returns false.

### Example

```sql
> SELECT is_variant_null(named_struct('metadata', X'010000', 'value', X'00'));
true
> SELECT is_variant_null(named_struct('metadata', X'010000', 'value', X'0C0D'));
false
> SELECT is_variant_null(NULL);
false
```
