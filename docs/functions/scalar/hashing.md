## `crc32`

Returns the CRC-32 checksum of the input as a BIGINT. The checksum is an unsigned 32-bit value, so the result is never negative. DataFusion has no built-in `crc32`.

```sql
crc32(expr)
```

### Arguments

- **expr**: String or binary expression. Strings are checksummed as UTF-8 bytes. NULL returns NULL.

### Example

```sql
> SELECT crc32('Spark');
1557323817
> SELECT crc32('');
0
> SELECT crc32(NULL);
NULL
```

## `sha1`

Returns the SHA-1 digest of the input as a 40-character lowercase hex string. DataFusion has no built-in `sha1`.

```sql
sha1(expr)
```

### Arguments

- **expr**: String or binary expression to hash. Strings are hashed as UTF-8 bytes. NULL returns NULL.

### Example

```sql
> SELECT sha1('Spark');
85f5955f4b27a9a4c2aab6ffe5d7189fc298b92c
> SELECT sha1(NULL);
NULL
```

### Alternative Syntax

```sql
sha(expr)
```

### Aliases

- sha

## `sha2`

Returns the SHA-2 digest of the input as a lowercase hex string. Unlike DataFusion's `sha224`/`sha256`/..., the result is a hex string rather than binary, and the bit length may vary per row. An unsupported bit length returns NULL rather than an error.

```sql
sha2(expr, bit_length)
```

### Arguments

- **expr**: String or binary expression to hash. Strings are hashed as UTF-8 bytes. NULL returns NULL.
- **bit_length**: Integer SHA-2 variant: 224, 256, 384 or 512. 0 is treated as 256. Any other value, or NULL, returns NULL.

### Example

```sql
> SELECT sha2('Spark', 256);
529bc3b07127ecb7e53a4dcf1991d9152c24537d919178022b2c42657f79a26b
> SELECT sha2('Spark', 128);
NULL
```
